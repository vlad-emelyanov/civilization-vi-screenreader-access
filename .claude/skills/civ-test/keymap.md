# Civ VI key bindings (generated)

Generated by `util\civctl.cmd keymap` on 2026-10-21 from the in-game Key Bindings list (Options.lua `DumpKeyMap`). Do not edit by hand; regenerate after rebinding keys or changing mod hotkeys (`Database/*.sql`).

"civctl key" is the argument for `util\civctl.cmd key <arg>`. These are in-game (World) hotkeys: they need a game in progress and no popup open. A blank key means unbound; `?` means civctl cannot send it yet (extend ConvertTo-CivctlKey).
