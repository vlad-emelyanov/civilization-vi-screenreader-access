# Civ VI key bindings (generated)

Generated by `util\civctl.cmd keymap` on 2026-10-23 from `InputSettings.json` (the user's bindings) plus the default gestures of the mod's `Database/*.sql` and the game's InputConfiguration (`util/keybindings.py`; no running game needed). Do not edit by hand; regenerate after rebinding keys or changing mod hotkeys (`Database/*.sql`).

"civctl key" is the argument for `util\civctl.cmd key <arg>`; prefer `util\civctl.cmd action <Action id>` in scripts (it looks the key up here, so a rebinding cannot break the script). These are in-game (World) hotkeys: they need a game in progress and no popup open. A blank key means unbound; `?` means civctl cannot send it yet (extend `_KEYS` in util/keybindings.py). Source: `user` = stored in InputSettings.json, `default` = not in the file yet (mod/game default).

**Unbound actions: Toggle Great Works Screen**

**Never send these (JAWS reserved keys; the harness refuses them): LensPlague = Insert**
