# Features and architecture

Current behaviour of the mod, by area. Present tense, no history (git log has that). Read `CLAUDE.md` and `docs/keynav-guide.md` first; open work is in `docs/backlog.md`, engine facts in `docs/engine-notes.md`, wording rules in `docs/speech-guidelines.md`.

- **Keys:** this file names only the entry key of a feature. The full key list, with the current bindings, is `ScreenReaderAccess/Assets/UI/Accessibility/HelpText.lua` (canonical, shown in game with Control+H). Do not copy key maps here.
- **Turn loop:** Enter = the game's Next Action. It selects the next unit that needs orders, opens the production/research/civic chooser, and ends the turn when nothing blocks. Everything below fills the gaps in that loop. N says what Enter will do.
- **"Unverified"** below means: no regress script covers it and it was never seen in the real game (code and unit tests only). Everything else has a `test/regress/*.txt` script or was seen in play.
- Pure wording lives in `Accessibility/*Text.lua` files with `test/lua/test_*.lua` tests. Files named `Foo_SRA.lua` in `UI/Replacements/` replace a game script with `ReplaceUIScript`; other overrides are `ImportFiles` copies (pristine commit first, then marked `ScreenReaderAccess` blocks). Why each method: `docs/engine-notes.md`. A `print( "ScreenReaderAccess: X copy loaded" )` in `Lua.log` proves a copy loads.

## Architecture

- **Hub context `InGameAccess`** (`UI/Additions/InGameAccess.{xml,lua}`, added with `AddUserInterfaces`): owns global hotkeys, the map cursor, modes (list navigation) and event-driven announcements. `InGameAccess.lua` (~360 lines) is wiring only: includes, Enter fallback, input handler, update loop, `Initialize` with the registered actions and events. `Hub` (global, defined there) holds what stayed in it. Prefer the hub over editing game files.
- **Hub modules** `Accessibility/Hub*.lua`, included just before `Initialize`, registered in `InGameActionData` only. Each defines ONE global table with its functions and state; cross-module calls go through the tables (`HubCore.SayResult( text )`); a name used by one module stays file-local. `test/lua/test_hubmodules.lua` loads the hub and all modules against a stub and runs `Initialize`.

| Module | Owns |
|---|---|
| `HubCore` | shared helpers (`Safe/Listen/After/SayResult`), `OpenMode/CloseMode`, shared `m_` state, speech hold queue (`Announce`, `UpdateSpeech`) |
| `HubCursor` | map cursor, plot speech, jumps, X scan of foreign units, select at cursor, Control+K |
| `HubTargets` | target modes (enter/confirm/cancel), attack previews, attack and capital keys, F8 reports toggle |
| `HubAnnounce` | N "what is next", selection / turn / ready announcements, loyalty and hint suffixes |
| `HubSettle` | X browsers: settle spots, builder tiles, activation tiles of great persons and others |
| `HubPlacement` | district / wonder placement browser |
| `HubMenus` | Tab unit actions menu, V diplomacy list, Control+R standing |
| `HubRegions` | top panel (Control+Y), notifications (Control+N), Control+G, Control+W |
| `HubCityReport` | Control+I city report and city management sub-lists |
| `HubEvents` | order results, combat lines, map events |
| `HubEnemies` | turn-start "what did the enemies do" line |
| `HubPlaces` | J places list (incl. Threats, Blind spots, Foreign lands), M send-a-unit lists |
| `HubOverview` | Shift+J area overview |
| `HubHelp` | Control+H help list (text: `HelpText.lua`) |
| `HubGamepad`, `HubPad`, `HubLenses`, `HubScreens` | controller buttons, the LB/RB ring and its two ring-only lists |

- **Reusable logic in `Accessibility/`** (`PlotDescription`, `SettleScan`, `PlacementScan`, `BuildScan`, `BlindSpots`, `DistrictAdvice`, `ResourceTech`, `StandingText`, ...). A helper a front-end file includes must be in BOTH `FrontEndActionData` and `InGameActionData`.
- **Game file overrides only where the data or callbacks live in that context** (UnitPanel, ProductionPanel, choosers, NotificationPanel, ActionPanel, screens). Check `DLC/Expansion1|2/UI/Replacements`: with Gathering Storm, `TopPanel` is replaced by the XP2 copy and `UnitPanel_Expansion2` includes `_Expansion1` which includes `UnitPanel`. Override the file that holds the code and confirm with a load print.
- **Cross-context calls** go through `LuaEvents.SRA_*`; pass plain data, never functions.
- **Input order:** the hub's `SetInputHandler` runs before `WorldInput` and `ActionPanel`; consuming KeyDown and KeyUp of a key in a hub mode is all a mode needs (a consumed Enter does not fire Next Action). `Keys` codes: engine-notes.
- **Hub context facts:** the hub calls `ContextPtr:SetHide( false )` first (a hidden context gets no input actions). The cursor plot is put at screen centre with `UI.LookAtPlotScreenPosition( x, y, 0.5, 0.5 )`; the real mouse follows 0.8 s after the last move, after `LuaEvents.SRA_CursorPlot( plotIndex )` so `PlotToolTip` does not read the plot twice.
- **End-turn text** (N) is read from the ActionPanel label `/InGame/HUD/ActionPanel/EndTurnText` (`ContextPtr:LookUpControl`), so expansion blockers are covered. N and Enter share one intent (`EnterIntent`).
- **Speech:** key results interrupt; events (new turn, notifications, combat) use `nointerrupt`. A popup that speaks sends `LuaEvents.SRA_SpeechHold( name, true|false )`; `HubCore.Announce` queues selection/turn/combat lines while a hold is active (max 6, deduped, holds expire after 60 s, cleared at turn end and load) and speaks them 0.4 s after the release. Key hints in spoken text use `SRKey` / `SRPadHint` / `SRKbHint` (see Controller).
- **Modes:** the unit menu, V list, X browsers, top panel, notifications, city report, places, overview and help are `OpenMode/CloseMode` entries of one `m_mode` (opening one closes the other); target modes refuse to open one; selection change, turn end, load and player change close it silently. Lists use `KeyNavList`.
- **Hub limits:** a Lua chunk holds 200 locals, so new state goes into module tables. `rawset` and (in `GameCore_Tuner`) `pcall` do not exist in the Civ Lua sandbox. Listeners are registered with `SRListen` and removed by `SRUnlistenAll()` on shutdown; a production panel open during a hot reload goes dead (reopen works).

## Front end

Path that works end to end: Main menu, Single Player, Create Game or Advanced Setup (all options, players, add/remove AI), Start Game, load screen, Enter begins. Files: `Assets/UI/Frontend/{MainMenu,AdvancedSetup,LoadScreen,LoadGameMenu,FrontEndPopup,StagingRoom,JoiningRoom}.lua`, `Options.lua`; reference implementations `MainMenu.lua` and `AdvancedSetup.lua`.

- **Setup pulldowns:** mod-side selection mode (Enter opens, Up/Down/Home/End say "value, i of n", Enter applies, Escape cancels). Map Select and Multi-Select popups are navigable. Exit confirmation popup works.
- **Load Game** (also in game; `LoadGameMenu.lua` and `LoadSaveMenu_Shared.lua` are registered in both action data): "N saves", Up/Down over saves (name, leader, civ, turn, date, "i of n"), Tab between groups (saves / options / buttons), Space reads full details, checkboxes, sort, Delete opens a confirmation. The in-game Save Game screen (`Menus/SaveGameMenu.lua`) edits the name through `KeyNavEditBox` and asks before overwrite/delete; "Game saved" comes from `Events.SaveComplete`.
- **Options** (every tab): Up/Down over tabs and Confirm/Restore/Back, Enter enters a tab, Left/Right change pulldowns and sliders (the mouse is parked off sliders). Key Bindings: Tab = next category, Enter rebinds, Delete clears; the engine records a rebinding only if the input handler returns false for the key. Confirm/Reset popups (incl. the 15 s countdown) work with Up/Down/Enter, Escape = last button.
- **Text fields** (`KeyNavEditBox.lua`; seed, LAN name, webhook URL, pedia search, chat): "label, edit, value|blank, Enter to edit"; typing is echoed; Enter commits, Escape restores. Engine facts: while an EditBox has focus the context's input handler gets no key events; Enter fires the commit callback; Escape reverts the text, fires the commit callback, and its KeyUp still reaches the context (the helper swallows it); the HasFocus callback gets the control, not a boolean; characters rejected by `SetNumberInput( true )` give no callback. `ChatEntry` has KeepFocus, so Escape only reverts the text: option `cancelOnRevert` treats an all-at-once revert as Escape (heuristic: Escape after one typed character or in an empty box does not end the edit; Enter says "Nothing sent").
- **Staging Room** (host side; client untested): Tab cycles Players / Buttons / Tabs; Enter or Right opens a player row's controls (slot, leader, team, color, difficulty, kick, add); Ready toggles ready or cancels the countdown; S reads the launch status; Tabs: Game Summary, Friends (Invite through the Steam API); C types a chat message, H reads the last 50 lines; incoming chat is spoken without interrupting.
- **JoiningRoom:** announces each status, Escape cancels; failures arrive as the FrontEndPopup.
- **Load screen** (`LoadScreen.lua`): speaks the whole text on open, which collides with the game's narrator (backlog M12). Enter begins the game once loaded.
- Known gaps / unverified: leader picker and city-state picker (Enter opens, no navigation inside; Left/Right on the setup screen covers it); Gathering Storm welcome popup; in-game multiplayer game parameters; Switch UI Layout popup; Staging Room client side.

## Map cursor and turn flow

- **Cursor:** Shift+Arrows move it and speak the plot (`PlotDescription.lua`). Order: a lens value (when a lens is on), a strategic or luxury resource with its class ("Iron (strategic), needs Bronze Working"), the position, then city, units, terrain, feature, bonus resource, river/coast, improvement, district, owner, yields ("unexplored"/"fogged"; fogged plots speak what the game's own tooltip does, units only when visible), and last the selected unit's suffix ("can settle", "Builder can build: Quarry"). The position is relative to the selected unit or city ("3 tiles north-east"), and after a jump also from the nearest city (below); a plot without such a resource starts with the position. I = detailed description. `.` = cursor to the selected unit/city. Control+Shift+Arrows jump 5 tiles. K selects your unit/city on the cursor plot (again: the next one there), Control+K walks all your units, Backslash = capital ("Capital: Rome"), always spoken.
- **Jumps** (notification Enter, X scan, places list) also say the position from the nearest own city ("7 tiles north-west of Rome"); single steps do not. The same position text (`HubAnnounce.PositionText`) is used on unit selection and in the places lists: when the nearest city of another player (civilization, city-state or free city, only cities whose plot we have revealed) is strictly closer than our nearest one, it comes first with its owner: "1 tile west of Seoul (Korea), 4 tiles east of Aquileia"; inside a foreign city "in Seoul (Korea)". A city-state named like its city is not repeated in brackets.
- **PlotToolTip** (override) drops `-----` lines, stays quiet for a plot the cursor already read and speaks only for a mouse that really moved.
- **Turn flow:** "Turn 5, 3600 BC" at turn start; "Turn ended" (only if the turn changed or the local player is inactive); "Turn not ended: <blocker>" when the engine reactivates the turn (unit needs orders after queued moves, World Congress waiting). Load announces once the turn is running; a unit selected during the load is announced after "Turn 1". A ready watch says "All done. Enter ends the turn" once per ready phase. Enter on an exposed settler/builder asks once more. Multiplayer (simultaneous turns), UNVERIFIED, MP only: after readying, the action panel says "Waiting for players" / "Waiting for NAME" and the turn stays active, so the mod says "Turn ended, waiting for other players" (and never "Turn not ended: Waiting for ..."); Enter on that label un-readies (`ACTION_UNREADYTURN`) and `Events.LocalPlayerTurnUnready` makes the mod say "Turn resumed" (interrupting), cancel its pending end-of-turn checks and re-arm the ready watch ("All done" follows once the label says "Next turn").
- **Selection announcement:** unit name, moves, activity ("exploring", "fortified", ...), position suffix ("in Rome", "1 tile east of Aquileia"), hints (promotion "Shift+U", upgrade with cost, escort, civilian danger), corps/army names, carrier cargo. City selection: name, population, production, growth, loyalty. A selection event for the unit already selected says nothing.
- **Enemies:** "Barbarian Scout spotted, 3 tiles south-west of Xi'an" (once per unit per 10 turns, max 4 per turn). `HubEnemies` speaks one turn-start line comparing hostile units within 6 tiles of a city or 3 of a unit with the last snapshot. A barbarian scout that has seen us (`GetBarbarianTargetPlayer() == us`) raises an alarm; 2+ barbarian soldiers near a city give a raid line; civilians near a hostile soldier a danger line; camps destroyed are counted once. Scenario-created scouts are never flagged (use a fixture's own).
- Known gaps / unverified: scout "escaped" / "killed" lines and "Raid continues" over real turns; city-in-danger warning only through the raid line (Ostia was captured with attack lines as the only warning); auto-explore end is not announced.

## Units and orders

- **Tab menu** (`HubMenus`, from UnitPanel's own action table via `LuaEvents.SRA_RequestUnitActions / SRA_UnitActions / SRA_RunUnitAction`; `Panels/UnitPanel.lua`): "Move To, key M, 1 of 6", disabled ones "unavailable: reason" and listed after all available ones (stable partition, `HubMenus.AvailableFirst`; the numbering follows), Space = tooltip. The mod's browsers are the first entries. Results are spoken from `UnitOperationStarted` (so game hotkeys speak too); Automate Exploration and Fortify Until Healed fire only `UnitOperationAdded`.
- **Reasons:** a disabled action or hotkey says why: no moves, already built, not possible on this tile, stacked-unit reason for Skip/Fortify/Sleep, "Danger" for exploring, ranged "no enemy it can target in range" (derived), city "needs walls" / "already attacked this turn" (hedged). Some units (an unescorted settler, a besieged unit) get no skip/sleep from the engine: Enter says "Cannot skip: ... move it, found a city or delete it".
- **Promotions:** "Promotion available, Shift+U" on selection; `Popups/UnitPromotionPopup.lua` lists every promotion of the class (have / available / locked: needs A or B); Enter promotes ("Promoted: X"). **Upgrade** (U): result or reason; selection hint "Upgrade to Pikeman available, 120 gold, U".
- **Great people** (U): "<name> activated: <effect>"; on the wrong tile "Cannot activate X: must stand on a completed Campus district. Nearest: Rome's Campus, 1 tile north-west"; generals' Retire asks first; Transfer to Another City is a target mode for non-traders.
- **Builders:** Tab menu drops tile-impossible entries, Remove Improvement warns before destroying ("Enter again to confirm"), cursor text ends "Builder can build: Quarry". Repair of pillaged items: "Repair X" / "Repairing X", reasons incl. enemy on the district.
- **Also:** escort (Shift+E; selection says "escorted by", a civilian moving alone near danger is warned); embarked land units ("Arrived, embarked"); trade outcomes come from `LuaEvents.SRA_TradeResult`.
- Known gaps / unverified: promotion-tree units (only the game's tree opens); Name unit; corps -> army and fleet names in real play; WMD/ICBM and PRIORITY_TARGET still click; coastal raid / sacrifice / hero commands ported by reading only; a city production auto-swap is not announced.

## Target modes

- Entered by M, R, W, Tab menu items or any key that sets an interface mode (`HubTargets`). Opening line "Move to: choose a tile ..." (attack mode, ranged, air and city ranged attack: "<Label>: choose a target with X for the next one, Shift+Arrows moves tile by tile, Enter to attack, Escape to cancel"; pad X = F13 walks the targets like the keyboard X); Shift+Arrows say "2 turns" / "unreachable" / "attack, 2 turns" (`GetMoveToPathEx`); Enter confirms (`MoveUnitToPlot`; direct `RangeAttack` / `AirAttack` / `CityCommandTypes.RANGE_ATTACK` requests; a real click for other modes); Escape cancels. Keys are always consumed; the mode resets when the unit dies, is deselected or the turn ends. Interface modes `MAKE_TRADE_ROUTE`, `TELEPORT_TO_CITY` (traders) and the `SPY_*` modes are chooser modes (`m_chooserModes`): the hub stays out of their way.
- **W = Attack:** ranged/air units enter their attack mode, melee units the move mode where only enemies are valid; jumps to the nearest enemy and reads the preview. The preview (`CombatManager.SimulateAttackInto`, `CombatText.lua`): "attack, 1 turn, Strength 20 against 17, deals 45 damage, target left with 2 of 100, you take 20", walls/city health/pillage/no combat, "would declare war on X" (`IsAttackChangeWarState`); Space lists modifiers; far targets say "Strength 33 against 15 when you reach it". The war dialog (`DeclareWarPopup.lua` override) is spoken and modal. No target: "No enemy in range of the X. Nearest enemy: ...".
- **X in attack modes** walks only attackable targets (`GetAttackTargets`, `GetCityAttackTargets`, melee: reachable hostile plots incl. cities/districts); hostile without war first, would-declare-war after; "Last target, X wraps to the first". Ranged mode preselects a target. Modes that list their own plots (deploy, rebase, corps) walk those.
- **Results:** "Your Warrior attacks Barbarian Spearman: Spearman takes 28 damage, 8 of 100 left" (from `CombatVisBegin`; only within 3 tiles of own units/cities; a city kill is attributed from the fight just announced since the engine reports killer -1 for city shots). `StatusMessagePanel` drops the game's duplicate lines only when the hub spoke within 2 s. "Attacking X" precedes a city shot; "Attack under way" holds until the result.
- **Nukes:** strike mode by keys; Stand down and Escape in the confirm dialog say "Launch cancelled. Still in nuclear strike mode ...".
- Known gaps / unverified: "Launching" line before a real nuke; war-confirm cancel during a nuke strike; air Deploy/Patrol to a real carrier or airstrip.

## Settler, builder and activation browsers (X)

- **Settler** (`SettleScan.lua`, formula in its header): candidates = the advisor's 5 picks (`GetSettlementRecommendations`) plus every revealed land plot within 6 tiles that `SettleScan_CanFound` allows (own rules: min city distance, mountains, wonders, foreign borders; plus `CanStartOperation( unit, FOUND_CITY, plot, false, true )`, which says no for every plot at 0 moves, then "B to found next turn"). Score: fresh water/coast, resources weighted per ring (ring 1 = the six neighbours; each resource once; plots another city owns do not count), food/production, hills, hazards, crowding, barbarians, travel turns, advisor bonus; sites within 2 tiles of a better one merge. Selection says "Can settle here, but floods. Best: 1 tile south-west, 1 turn, river, coast, marble. X to browse." or "Here is good ..." / "Best spot is clearly better ..." (score-gap thresholds). Browser items add distance to the nearest own and foreign city; Space = all reasons and ring detail; Enter moves (or "B to found the city here"); Escape restores the cursor. Cursor text while a settler is selected ends "can settle" / "cannot settle: too close to Nazca". Reasons name only cities we have seen.
- **Builder** (`BuildScan.lua`, `HubSettle`): "Tiles to improve near Rome, 5 tiles"; items lead with the improvement ("Farm plus 1 food, 2 tiles north-east, Wheat, 1 turn, worked"); resource tiles first, then worked, then the rest; Left/Right switch city; Enter walks there (own tile: builds/menu; arrival builds with the danger guard); a "Later" group lists tiles that need a tech ("Mine needs Bronze Working", `ResourceTech.lua`). Yield changes are base values (no adjacency/policy bonuses).
- **Activation tiles** (great persons with `ActivationHighlightPlots`, archaeologists, naturalists, rock bands, completed-district targets): same browser; "Arrived. Enter activates".
- Known gaps: weights tuned by eye on about 8 starts; archaeologist, naturalist and rock band tiles untested; the builder browser refuses at 0 moves while the act browser opens.

## Choosers and trees

- **Research / Civics choosers** (`Choosers/*.lua`): turns, boost/inspiration, unlocks, recommended; Space adds cost, progress and your yield; the title uses the live researching tech. Tech completed popup: name, unlocks, "Enter to continue, G or F7 for Change Policies"; boost and natural wonder popups are spoken.
- **Production panel** (`Panels/ProductionPanel.lua`): opens from Next Action or Tab on a selected city. Tab cycles Production / Queue / Purchase gold / Purchase faith; items "Warrior, 7 turns, 40 production, recommended", purchases "can't afford, 30 more needed" / "unavailable: reason"; Enter calls the panel's own functions and the result comes from `CityProductionQueueChanged` / treasury events ("Producing X, N turns", "Queued X", "Bought Scout, 0 gold left"). Opens on the current production or the recommended item; Space = description first; a 0.6 s guard after a real open swallows a double Enter. Districts and wonders enter the placement browser. PageUp/PageDown jump between groups, spoken with the count ("Units, 12: Warrior, ..."). In queue mode the game reopens the panel after a placement (as it keeps it open after a unit pick); the list is then announced afresh so the old focus is not stale. Gaps: no keyboard path for corps/armies, queue reordering/removal or the Manager tab.
- **Placement browser** (`PlacementScan.lua`, `HubPlacement`): opens when the interface mode becomes DISTRICT_PLACEMENT / BUILDING_PLACEMENT: "Place Campus for Uruk, 17 tiles. Best: 1 tile west, plus 2 Science, removes Stone." Items sorted by adjacency with tile cost and what gets removed; tiles whose purchase the player cannot afford sort after all placeable ones (owned or affordable) and say "needs N more gold", so "Best:" is a placeable tile; Space = adjacency; Shift+Arrows say valid / purchasable / "can't place here: reason"; Enter asks, second Enter requests `BUILD` (or district `PURCHASE`), then `LuaEvents.SRA_ExitPlacement( false )` (hook in `WorldInput.lua`). An unowned tile is bought with its own `PURCHASE` command (balance checked first: `CanStartCommand( PURCHASE )` ignores it). Real refusal reasons (population, district cap) end the mode without spending gold. Escape: "Placement cancelled". Unverified: purchase with faith.
- **Government** (`Screens/GovernmentScreen.lua`): Policies / Governments / My Government tabs (Tab); Confirm says why it is disabled; two-step Escape for unconfirmed changes ("Government not changed"); confirmation popups are navigable. Unverified: an actual government change and the anarchy variant.
- **Pantheon chooser** (`Choosers/PantheonChooser.lua`): Enter selects, Enter again confirms.
- **Religion screen** (`ReligionScreen.lua`, L; helper `ReligionText.lua`): one `KeyNavList` over whatever panel shows (modes working / religion / beliefs / confirm / view / all); founding raises the notification "Religion founded: choose a name and beliefs. Control+N, then Enter on 'Choose Religion'" (no screen opens by itself). Custom names go through `KeyNavEditBox`. The screen shows stale faith until the next turn (engine).
- **Tech tree (T) and Civics tree (C)** (`Screens/TechTree.lua`, `CivicsTree.lua`, shared `TreeNav.lua` + `TreeText.lua`): Left/Right = era, Up/Down = node, Space = details, Enter = set target (path queued, replaces the queue; far targets say "Target: Mass Production, path: ..., 27 turns" with the SUM of per-tech turns), Shift+Enter appends, J current, Q queue, F search (name match, then `Search.Search` full text). Unrevealed nodes are counted, not named (Tech/Civic Shuffle). Techs that unlock an improvement for a resource near your cities say so, and a list key shows them nearest first.
- Known gaps / unverified: queue position numbering assumed (current = 1); ResearchChooser slide-out when the tree opens from it.

## City report and city management (Control+I)

- Region for the selected city, else the city on the cursor, else "No city selected. Backslash selects the capital" (Control+I reads the selected city, not the one under the cursor when both exist). Items: population with housing first ("Population 6 of 7 housing, plus 4 food, grows in 11 turns"), amenities, loyalty, religion (right after loyalty: majority, followers), power (Gathering Storm, after loyalty: "Power 4 of 6 needed, underpowered", Space lists sources), defense, production, districts and buildings, district spots (best district fits, `DistrictAdvice.lua`), citizens, resources, great works. Space = the game's breakdown (`GetYieldToolTip`, housing/amenity sources, loyalty). "may turn to X" only when loyalty is falling or below Loyal.
- Data: `CityReportGather.lua` calls the game's `GetCityData` (`include( "CitySupport" )` in a `pcall`), wording `CityReportData.lua`. Specialists = worker counts of the district plots; working tiles = population minus specialists.
- **Management sub-lists** (Enter on "Focus", "Tiles", "Specialists"): yield focus/ignore toggles (replicating `CityPanel.SetYieldFocus/SetYieldIgnore`), tile list (worked/locked, buy a tile with a price question, replicating `PlotInfo.OnClickCitizen` / `OnClickPurchasePlot`), specialists (Enter adds, Backspace/Delete clicks until the count drops by one). Works without entering CITY_MANAGEMENT; "Nothing changed" after 2 s if the engine did not react. State is in the table `MG` (locals limit).
- Tab from the report opens production; Escape from production opened this way returns to the report only.
- Known gaps: specialist "+N each" ignores bonuses; no keyboard buy/reorder from the report.

## Regions

- **Top panel** (Control+Y, `TopPanelData.lua`, same APIs and number formats as `TopPanel.lua`): gold, science, culture, faith, tourism, favor, strategic resources (only when had or needed), research, civic, turn/date, era, envoys, trade routes; Space = the game's tooltip; Enter on research/civic opens the chooser. Control+G = one-line yields. Unverified: turn-limit format, era score thresholds (Rise and Fall).
- **Notifications** (Control+N, `Panels/NotificationPanel.lua`): newest first with a subject after the title (`NotificationSubject.lua`); Space = full text and "Blocks ending the turn"; Enter activates like a click (stacked ones: the game picks the target); Delete dismisses; M sends a unit to its place. Arrivals are announced (nointerrupt, bursts merged, deduped by player:id); `SRA_NotificationTexts` supplies English text where the game ships none.
- **Places list** (J, `HubPlaces`): categories Your cities, Your units (with activity, grouped by unit type: PageUp/PageDown jump between types, spoken with the count; opens on the selected unit), Points of interest (villages, camps with guards, natural wonders; clan line in Barbarian Clans mode), Notifications with a place, Foreign cities, Foreign lands (borders of met civs), Threats (when active), Blind spots (revealed-but-unseen clusters 4-8 tiles from cities, where camps spawn). Tab/Control+Tab = category, Space = plot + position, Enter = cursor there or select the unit, M = "Send a unit to X" (units that can reach it, by turns; "next to Rome" fallback for occupied places; escort and attack-party variants), T on a clan camp opens Treat With Clan (`TreatWithTribePopup_SRA.lua`). In a target mode the list only moves the target cursor ("Next to Rome" when unreachable); a ship's list leaves out places out of its water reach. Camps after a load are "as last seen" (no engine API).
- **Shift+M** sends a unit to the cursor tile (`HubPlaces.SendHere`). **Shift+J area overview** (`HubOverview`, revealed plots only): Area (within 3 tiles), Continent (`Map.GetVisibleContinentPlots`) and one item per compass direction within 8 tiles. **Control+F map search** (`Popups/MapSearchPanel.lua`, `MinimapPanel.lua`): type words, Enter searches, Down/Up step through matches and move the map cursor. **Control+R standing** (`StandingText.lua`): rank among met civs per category plus the weakest; the V list carries the numbers.
- **Lenses** (number keys 1-9, 0; `LensText.lua`, no game file overridden): the hub registers the same actions and speaks the lens name and legend 0.3 s later, "<Name> lens off" on end; while a lens is on the cursor text leads with its value (appeal, religion, continent, settler, loyalty, government). Political, Tourism, Empire and Power only get on/off and a legend. A lens turned on with the mouse names itself from the layers events; Power falls back to "Lens on".
- Known gaps / unverified: the numpad Divide key (lens off, era panel) never reaches the game from the harness; `HubPlaces.OrderHint` "Shift+W wakes it" branch (Sleep refused for every unit tried); which `GetActivityType` an auto-exploring unit has ("exploring" is inferred).

## Diplomacy and deals

- **V list** (`HubMenus`): "leader, civ, relationship" with score/military/science/culture/gold/faith numbers, you first; Enter opens the game's diplomacy screen. `DiplomacyActionView.lua` (override): first-contact statement and answers, the overview (things you can propose, Discuss / Casus Belli submenus, costs, disabled reasons; available entries first, unavailable ones after them via `SRAvailableFirst`, which the Tab unit menu uses too) as a second `KeyNavList`; cinema mode: Enter ends the scene, then applies the answer; "Diplomacy closed". An advisor popup is held while diplomacy is up. Notifications name both parties of a war or peace.
- **Deal screen** (`UI/Replacements/SRA_DealView.lua`, Gathering Storm copy; `DealSpeech.lua`): opens with "Deal with X of Y. <leader text> You give ...; They give ... Focus: <section>, <item>". Sections Deal / Your items / Their items / Actions (Tab, Control+Tab; S reads the summary). Your/Their items: Enter adds (agreements with options open an option list). Deal: Enter or Delete removes, Left/Right change an amount by 1 (Shift 10). Actions: the visible buttons. AI answers are spoken once things were quiet for 0.45 s ("They accept the deal.", "Deal changed. <summary>"). Items are identified by from/type/subtype/value/duration, not deal item ID.
- Known gaps / unverified: "stop asking" buttons, editing an agreement's value (remove and re-add), collapsing groups, human-to-human multiplayer (a report from a real Internet game said no goods to trade appeared; not reproducible against an AI in LAN or a private Internet game, see engine-notes 'Multiplayer'; the deal screen logs `DiplomacyDealView open: ... avail mine/theirs` for the next report); AI-proposal path seen once on a simulated offer; "Item no longer available" on an AI deal gives no reason (game text); AI deal rejection gives no hint; Enter in the Deal section removes an item by design.

## City-States, governors, religion, trade, great people, espionage, congress, era, climate, reports

All of these are keyboard lists over the game's own screen data (rebuilt at key time, actions call the screen's own functions, all keys swallowed while shown except function keys and Control/Alt chords).

- **City-States** (F2; `PartialScreens/CityStates.lua`): one item per met city-state, Space = bonuses, suzerain, quests. Send mode (forced while envoys are left): Enter/Right/= add, Left/Backspace/- remove, C confirms, Escape discards (two-step when unsent). A = actions: Show on map (`LuaEvents.SRA_CursorTo`), Levy military, Make peace (unverified). Numpad plus/minus are not used (JAWS).
- **Governors** (F10 or blocker; `UI/Replacements/Governor{Panel,AssignmentChooser,DetailsPanel}_SRA.lua`): Enter opens "Actions for X" (Appoint, Assign, Promote, Abilities). Secret-society governors are skipped (not owned).
- **Trade** (`Choosers/TradeRouteChooser.lua`, `TradeOriginChooser.lua`, `TradeOverview.lua` F4; `TradeText.lua`, `TradeOverviewText.lua`): destinations sorted by origin yield; Enter asks, second Enter requests. Overview tabs My Routes / Routes to my Cities / Available Routes, B toggles benefits, Enter selects the trader. No "turns left" (not in the route data); the filter pulldown is unreachable.
- **Great People** (O; `Popups/GreatPeoplePopup.lua`): one item per timeline entry, Enter = Recruit / Pass / Patronize with gold or faith (spoken after the engine confirms); Tab = previously recruited. **Great Works** (Control+W; `GreatWorksOverview.lua`, `GreatWorkShowcase.lua`): slots per building with theming status, Enter picks up and places (`MoveGreatWork`), V describes the work; the gallery button is only reachable from the showcase.
- **Espionage** (F3 `PartialScreens/EspionageOverview.lua`, `Choosers/EspionageChooser.lua`; `EspionageText.lua`): operatives, city activity, mission history; destination then mission list, Enter asks, second Enter starts (success is told optimistically). Mission and escape popups speak; escape needs a fleeing spy (`espionage-escape.txt` is manual).
- **World Congress** (`UI/Replacements/WorldCongress{Popup,Intro,BetweenTurns}_SRA.lua`, `WorldCongressText.lua`): vote phase (Left/Right option, = adds a vote and says the next cost, - removes, T or Enter picks the target, N next), summary, review tabs; BetweenTurns says who is waiting. `WorldCrisisPopup_SRA.lua` speaks emergencies. - **Era** (`EraReviewPopup_SRA.lua`, `DedicationPopup_SRA.lua`, `EraProgressPanel_SRA.lua` Control+E, `HistoricMoments_SRA.lua`): new era line, dedication chooser (Enter selects, C confirms), era progress list, historic moment and timeline popups.

- **Reports** (F8; `Screens/ReportScreen.lua`, `ReportText.lua`): Yields, Resources, City Status, Gossip; items built from the screen's file-local data with `SRA_*` hooks. Gossip filters unreachable.
- **World Rankings** (F1; `PartialScreens/WorldRankings.lua`, `RankingsText.lua`): Overview with your place per victory type, then one tab each; H = what the victory type is about. Overflow tabs unreachable.
- **Civilopedia** (F9, advisor "Tell me more"; `Civilopedia/CivilopediaSupport.lua`, `PediaText.lua`): page text captured by hooks in the layout helpers every page script calls; Enter follows links, Backspace goes back, F searches.
- Known gaps: hotseat and other players' turns untested everywhere; fixed English phrases are not localized.

## End game

`EndGame/EndGameMenu.lua`: says the result on show ("Victory: Science victory, you, Rome. <blurb>"), then once the fade-in and movie are over (`SRTryOpen`) a list of pages Info / Rankings / Graphs (Tab) and buttons (Replay movie, Historic moments, One more turn, Main menu, Exit to desktop), Enter calls the button callbacks (`EndGameText.lua`). ## Help

Control+H (`HubHelp`, text `HelpText.lua`): sections of `{ action, default, text }` or `{ keys, text }`; action entries ask `Input.GetGestureDisplayString( Input.GetActionId( name ), 0 )` at open time so rebinding shows; Tab/Control+Tab = section, letter jumps to a section ("No section starting with X"), Space repeats. Opens inside a target mode too; not in the front end. In controller mode the Controller section is listed first. Every new shortcut needs an entry (`test/py/test_helptext.py` checks input actions).

## Controller

Design and button map: `docs/controller-plan.md`. The console app polls XInput and injects keys (A Enter, B Escape, Y Space, stick arrows, D-pad Home/End/Tab, others F13-F24; a held LB/RB turns stick/D-pad up/down into PageUp/PageDown); `HubGamepad` (table `Gamepad.lua`, catcher in `WorldInput.lua`) interprets them by context; `HubPad` runs the LB/RB ring. Spoken hints name the pad button through `SRKey`, `SRPadHint`, `SRKbHint` (expanded by the console app, `KeyHints.cs`). Pad X on the bare map opens the selected unit's browser when it has one; lists advertise ", Y for details" once per open (pad only). In lists and in screens with their own Tab handling (tree, deal view, reports ...; `Gamepad.TranslateListKey` / `WrapInput`) the D-pad up/down move one item, right/left are Right/Left, LB/RB are the previous/next section or tab (LB/RB reach the screen while a game screen is open; Places treats its categories as sub-stops of the ring), and PageUp/PageDown (held bumper + up/down) jump to the previous/next group (production panel, Places "Your units" by type); see controller-plan.md, "In lists". Gaps: Options, save game menu, world congress, map search, advisor popup, front end screens without `KeyNavList` still get Home/End/Tab as keys.
