# Fixture pt-faith-t163 (Rome, Buddhism founded). A Missionary with the founded religion and 2 charges is created in Antium (no majority religion; Rome is Buddhist, so Spread is not offered there): Spread Religion from the Tab menu says which religion spread, in which city and how many spreads are left; at the last charge the unit is consumed and the line says no spreads left. Space gives a description instead of repeating the name. Tuner: GameCore unit:GetReligion():SetReligionType/ChangeSpreadCharges (the UI-state unit:GetReligionType() stays -1 until the unit acts).
# covers: **/HubEvents.lua **/HubMenus.lua **/ReligionText.lua **/UnitPanel.lua
# no-share-load: spawns a Missionary and spreads religion
load pt-faith-t163
clear-advisors
lua GameCore_Tuner local u=Players[0]:GetUnits():Create(GameInfo.Units["UNIT_MISSIONARY"].Index, 70, 24) local r=u:GetReligion() r:SetReligionType(1) r:ChangeSpreadCharges(2-r:GetSpreadCharges()) return r:GetSpreadCharges()
lua InGameAccess for _,u in Players[0]:GetUnits():Members() do if GameInfo.Units[u:GetType()].UnitType=="UNIT_MISSIONARY" then UI.SelectUnit(u) break end end
key Tab -Settle 1500
expect Missionary actions, \d+ options
expect Spread Religion, 1 of
key Space -Settle 800
expect After this action
key Enter -Settle 2500
expect Buddhism spread in Antium, 1 spread left
lua GameCore_Tuner local u=Players[0]:GetUnits():Create(GameInfo.Units["UNIT_MISSIONARY"].Index, 70, 24) local r=u:GetReligion() r:SetReligionType(1) r:ChangeSpreadCharges(1-r:GetSpreadCharges()) return r:GetSpreadCharges()
lua InGameAccess for _,u in Players[0]:GetUnits():Members() do if GameInfo.Units[u:GetType()].UnitType=="UNIT_MISSIONARY" and u:GetSpreadCharges()==1 and u:GetMovesRemaining()>0 then UI.SelectUnit(u) end end
key Tab -Settle 1500
expect Spread Religion, 1 of
key Enter -Settle 2500
expect Buddhism spread in Antium, no spreads left
