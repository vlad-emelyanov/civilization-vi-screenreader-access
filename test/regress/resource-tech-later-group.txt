# Written blind (round 23, G1). Unverified.
# Builder browser (X): after the tiles the builder can improve now, a "Later" group lists resource tiles that still need a tech or
# civic. The header counts them ("2 tiles, 1 later"); End goes to the last item, which is a Later item; Enter says what is missing
# and the cursor stays on the tile. The first lua step errors when the capital has no such tile.
# covers: **/BuildScan.lua **/HubSettle.lua **/ResourceTech.lua
# no-share-load: scenario builder-by-forest
load early-t60
scenario builder-by-forest
clear-advisors
lua GameCore_Tuner local c = Players[0]:GetCities():GetCapitalCity(); Map.GetPlot(65, 32):SetOwner(0, c:GetID()); Map.GetPlot(56, 34):SetOwner(0, c:GetID()); return 1
lua InGameAccess for _,u in Players[0]:GetUnits():Members() do if GameInfo.Units[u:GetType()].UnitType=="UNIT_BUILDER" then UI.SelectUnit(u) break end end
key X -Settle 2000
expect ^Tiles to improve near \w+, \d+ tiles?, \d+ later
key End -Settle 800
expect ^Later: .+ near \w+, .+ needs .+
key Enter -Settle 800
expect ^Not yet: needs .+
key Escape -Settle 800
expect ^Closed
no-lua-errors
