# Verified in game 2026-10-22. Founding a religion with a Great Prophet on medieval-t100 (util/scenarios/prophet-ready.lua places a Holy Site and the prophet).
# covers: **/ReligionScreen.lua **/ReligionText.lua **/UnitPanel.lua
# Found Religion is the first entry of the prophet's Tab menu; the game then raises a "Choose Religion" blocker; L opens the religion screen in its founding mode (Control+N would list the blockers in a varying order).
# no-share-load: scenario prophet-ready, founds a religion
load medieval-t100
scenario prophet-ready
clear-advisors
lua InGameAccess for _,u in Players[0]:GetUnits():Members() do if GameInfo.Units[u:GetType()].UnitType=="UNIT_GREAT_PROPHET" then UI.SelectUnit(u) break end end
key Tab -Settle 1500
expect ^Great Prophet actions, \d+ options
expect ^Found Religion
key Enter -Settle 3500
key L -Settle 3000
expect ^Found a religion: choose a religion, \d+ available\. .+, 1 of \d+
key Down -Settle 600
expect \d+ of \d+$
key Enter -Settle 800
expect selected\. Enter to continue
key Enter -Settle 1500
expect ^Choose beliefs for .+: 2 beliefs to choose
key Enter -Settle 1000
expect ^Chose .+
expect ^Choose beliefs for .+: 1 belief to choose\. Chosen: .+
key Enter -Settle 1000
expect ^Chose .+
expect ^Confirm\. Found .+ with .+ and .+
key Enter -Settle 2500
expect (?i)^.+ has .+ and .+
no-lua-errors
