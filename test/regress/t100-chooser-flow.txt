# Merged scripts (one load instead of three), fixture medieval-t100 (production chooser of Rome):
#  - t100-chooser-closes-on-v (verified 2026-10-23): V with the production chooser open closes it and the diplomacy list speaks.
#  - t100-chooser-enter-guard (verified 2026-10-23): a quick second Enter after Next Action does not pick the recommended item (0.6 s guard);
#    Enter after the guard does; Tab (re-open of the list) followed by an immediate Enter works (Tab disarms the guard).
#  - t100-next-in-placement (written blind 2026-10-23): N while placing a district says what Enter does there, not the end-turn label.
# Between parts the chooser / placement is closed with Escape (neutral map state again).
# covers: **/ProductionPanel.lua **/KeyNavList.lua **/HubAnnounce.lua **/HubPlacement.lua
# no-share-load: Enter picks the next unit / production
load medieval-t100
clear-advisors
# --- part from t100-chooser-closes-on-v ---
key Enter -Settle 2000
expect ^Rome, choose production
action KeyNavDiplomacy -Settle 2000
expect ^Diplomacy, met civilizations
expect ^Dido, Phoenicia
key Escape -Settle 1500
expect ^Closed
key Enter -Settle 2000
expect ^Rome, choose production
# back to the map: close the chooser that the last Enter reopened
key Escape -Settle 1500
expect ^Production closed
# --- part from t100-chooser-enter-guard ---
key Enter -Count 2 -Fast -Settle 100
expect ^Rome, choose production
expect-not ^Place
key Tab -Settle 50 -NoQuiet
key Enter -Settle 1500
expect ^Place .* for Rome
key Escape -Settle 1200
key Escape -Settle 1200
# --- part from t100-next-in-placement ---
key Enter -Count 2 -Settle 800
key Tab -Settle 600
key Enter -Settle 1500
expect ^Place .* for Rome
key N -Settle 600
expect ^Placing .*Enter on a tile asks to place it
key Escape -Settle 1200
key Escape -Settle 1200
no-lua-errors
