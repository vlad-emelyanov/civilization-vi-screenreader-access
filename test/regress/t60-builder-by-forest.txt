# Verified 2026-10-22. Scenario builder-by-forest on early-t60: the builder is selected through InGameAccess (UI.SelectUnit); Tab lists its actions.
# no-share-load
load early-t60
scenario builder-by-forest
clear-advisors
lua InGameAccess for _,u in Players[0]:GetUnits():Members() do if GameInfo.Units[u:GetType()].UnitType=="UNIT_BUILDER" then UI.SelectUnit(u) break end end
key Tab -Settle 1500
expect ^Builder, \d+ of \d+ moves
expect ^Builder actions, \d+ options
key Escape -Settle 1000
