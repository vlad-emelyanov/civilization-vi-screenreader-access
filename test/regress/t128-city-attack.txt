# Verified 2026-10-23. City ranged attack: Enter on the "City Ranged Attack" notification announces "Attacking X", and a kill by the city is told ("X killed by Ostia").
# covers: **/CombatText.lua **/InGameAccess.lua **/HubTargets.lua **/HubEvents.lua
# options: animations
# Setup: end turn 128 (barbarians approach Ostia), weaken the barbarian crossbowman with the tuner so Ostia's shot kills it.
# no-share-load: Enter ends the turn, attacks
load pt-t128
clear-advisors
key Enter -Settle 1500
expect (?i)turn ended
wait Turn 129 -Timeout 90
clear-advisors
lua GameCore_Tuner local n=0; for i=0,63 do local p=Players[i]; if p and p:IsBarbarian() then for _,u in p:GetUnits():Members() do if GameInfo.Units[u:GetType()].UnitType=="UNIT_CROSSBOWMAN" then u:SetDamage(70); n=n+1 end end end end return n
key Enter -Settle 1500
expect ^City ranged attack: choose a tile
expect valid target, Ranged strength \d+ against \d+.*Barbarian Crossbowman
# G2/G5 (verified 2026-10-26): the city preview comes from the city's district component (as the game's UnitPanel), so the line has strengths.
key Space -Settle 800
expect (Strength|Ranged strength) \d+|No modifier preview for a city attack|modifier
key Enter -Settle 8000 -NoQuiet
expect ^Attacking Barbarian Crossbowman
expect (?i)crossbowman killed by Ostia
no-lua-errors
