# Round 24: Enter with a builder (or settler) outside a city and a barbarian soldier within 3 tiles warns "Builder exposed: ... Enter again
# ends the turn anyway" and does not end the turn; any other key in between cancels (the next Enter warns again); a second Enter ends it.
# Fixture pt-early-t64: builder 3 tiles south-west of Rome, barbarian archer 3 tiles east of it. Our soldiers are removed so the blockers
# are only production, the builder, the settler (Space skips them) and the city's ranged attack.
# covers: **/HubEnemies.lua **/HubAnnounce.lua **/InGameAccess.lua
# no-share-load: removes units, ends the turn
load pt-early-t64
clear-advisors
lua GameCore_Tuner local p=Players[0] for _,u in p:GetUnits():Members() do local t=GameInfo.Units[u:GetType()].UnitType if t~="UNIT_BUILDER" and t~="UNIT_SETTLER" then p:GetUnits():Destroy(u) end end return 1
lua InGameAccess return HubEnemies.ExposedText((HubEnemies.ExposedCivilians(3)))
expect-lua ^Builder exposed: Barbarian Archer 3 tiles east\. Enter again ends the turn anyway$
key Enter -Settle 1500
key Enter -Settle 1500
key Enter -Settle 1500
key Space -Settle 1200
key Space -Settle 1200
key Space -Settle 1200
key Enter -Settle 1500
key Enter -Settle 2000
key Enter -Settle 2000
expect ^Builder exposed: Barbarian Archer 3 tiles east\. Enter again ends the turn anyway$
key Down -Settle 800
key Enter -Settle 2000
expect ^Builder exposed: Barbarian Archer 3 tiles east\. Enter again ends the turn anyway$
key Enter -Settle 4000
expect Turn ended
no-lua-errors
